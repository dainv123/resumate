# 🎬 Demo Video Script - "Từ nothing → CV chỉ vài giây"

## 📋 Video Overview
- **Duration:** 30 seconds
- **Format:** Vertical (9:16) for TikTok/Instagram Reels
- **Style:** Fast-paced, modern, tech-focused
- **Message:** Show the magic of creating a CV from nothing in seconds

## 🎯 Video Structure

### Scene 1: Problem Setup (0-5 seconds)
**Visual:**
- Split screen showing empty workspace on left, Job Description on right
- Person looking frustrated, scratching head
- Clock ticking in background

**Text Overlay:**
```
"Tạo CV mới... 😰"
"2-3 giờ chỉnh sửa"
```

**Audio:**
- Tense, ticking sound
- Sigh of frustration

### Scene 2: Solution Introduction (5-10 seconds)
**Visual:**
- Resumate logo appears with sparkle effect
- Clean, modern interface slides in
- Bright, optimistic color scheme

**Text Overlay:**
```
"Resumate AI 🤖"
"Từ nothing → CV chỉ vài giây"
```

**Audio:**
- Upbeat, hopeful music starts
- Gentle whoosh sound

### Scene 3: The Magic (10-20 seconds)
**Visual:**
- Paste Job Description into input field
- AI processing animation with countdown timer
- CV building in real-time with visual elements

**Text Overlay:**
```
"Paste Job Description..."
"AI đang phân tích..."
"Tạo CV tự động..."
"15... 10... 5..."
```

**Audio:**
- Fast-paced, energetic music
- Typing sounds, AI processing beeps
- Countdown sound effects

### Scene 4: Result Reveal (20-25 seconds)
**Visual:**
- Beautiful CV appears with professional layout
- Success animation (checkmarks, sparkles)
- Before/After comparison

**Text Overlay:**
```
"✨ CV hoàn chỉnh!"
"30 giây thay đổi mọi thứ"
```

**Audio:**
- Triumphant music crescendo
- Success sound effects

### Scene 5: Call to Action (25-30 seconds)
**Visual:**
- Resumate logo with website URL
- Download/Share buttons animation
- Social proof elements

**Text Overlay:**
```
"Thử ngay tại resumate.com"
"#ResumateMagic"
```

**Audio:**
- Call-to-action music
- Brand sound effect
